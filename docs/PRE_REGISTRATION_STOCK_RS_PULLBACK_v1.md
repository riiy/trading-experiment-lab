# STOCK_RS_PULLBACK_v1 预注册

## 1. 研究问题

在 A 股高流动性股票中，若个股相对沪深300持续强势，并出现首次有序缩量回踩，随后重新站上回踩日高点，是否能在 5–10 个交易日内获得稳定正收益？

## 2. 与家庭资产配置的关系

家庭核心资产配置使用 ETF，已独立执行。Trading Experiment 使用股票，账户额度 30,000 元，不得影响家庭核心资产配置。

## 2.1 验证样本范围修订

正式验证与账户仿真只使用冻结的近十年样本：`2016-07-17` 至
`2026-07-17`。窗口前可使用 60 个交易日的指标 warmup，但 warmup 不产生
信号、交易、绩效或账户仿真结果。

`STOCK_RS_PULLBACK_v1_MAPPING_UNEVALUABLE_DIAGNOSTICS_v1` 中在该窗口出现
raw/qfq 映射歧义的 21 个代码，将因数据质量原因整体排除。排除依据不使用
这些代码的信号、交易或收益表现；具体清单冻结在 Setup 配置中。

## 3. 适用账户

- 账户：Trading Experiment
- 本金上限：30,000 元
- 单笔最大计划亏损：500 元
- 第一阶段 Micro Live 单笔计划亏损：300 元
- 最大同时持仓：1 只
- 当前交易权限：false

## 4. 股票池

- A 股非 ST、非 *ST
- 上市满 180 天
- 近 20 日平均成交额 ≥ 3 亿元
- 一手金额 ≤ 15,000 元
- 排除停牌、刚复牌、一字涨跌停
- 排除近期重大利空（当前代码未接入事件数据，正式验证前不能视为已执行）

第一版只验证 A 股。港股通后置。

## 5. 强势定义

候选股必须同时满足：

1. 过去 20 日收益 > 沪深300过去 20 日收益 + 5%；
2. 收盘价 > MA20；
3. MA20 > MA60；
4. 近 20 日内创过 20 日新高。

## 6. 回踩定义

出现强势后，等待首次有序回踩：

1. 从近 10 日高点回撤 3%–8%；
2. 回踩日成交量 < MA5；当前实现的 MA5 窗口包含回踩日，正式验证前需确认是否改为严格的前 5 日均量；
3. 收盘价不破 MA20；
4. 收盘价不破前一段突破阳线实体中点。

## 7. 入场规则

回踩后，价格重新站上回踩日高点，次日开盘买入。

## 8. 退出规则

- 结构止损：回踩低点下方；
- 目标：2R；
- 最长持有：10 个交易日；
- 5 个交易日无上攻则退出；
- 往返成本：0.20%。

## 9. 风险控制

```text
每股风险 = 入场价 - 止损价
最大股数 = 单笔最大计划亏损 / 每股风险
资金占用 = 入场价 × 买入股数
```

若资金占用超过 30,000 元，或不足一手仍无法满足风险控制，该信号无效。

## 10. 回测数据要求

- 使用前复权或等价连续价格体系；
- 明确停牌、涨跌停、上市日期、ST 状态；
- 不得使用未来函数；
- 信号日之后的数据只能用于入场、退出和验证；
- 输出 invalid trade 的具体原因。

## 11. 通过标准

必须全部满足：

- 有效交易数 ≥ 80；
- mean net return > 0；
- median net return ≥ 0；
- Profit Factor > 1.20；
- best_3_removed_mean ≥ 0；
- Top3 contribution ratio ≤ 100%；
- 至少 2 个年度或市场阶段为正；
- 不依赖单一行业或单一股票。

## 12. 账户仿真要求

历史验证 PASS 后，才能进行 30,000 元账户仿真。账户仿真需要验证：

- 单笔计划亏损 ≤ 500 元；
- 一手金额 ≤ 15,000 元；
- 最大持仓 ≤ 1；
- 资金占用 ≤ 30,000 元；
- 连续亏损、月度亏损、总回撤触发暂停规则。

## 13. Micro Live 启动条件

同时满足：

1. 历史验证 PASS；
2. 账户仿真 PASS；
3. 连续 20 个纸面信号无规则破坏；
4. 生成正式交易票；
5. 人工确认。

## 14. 禁止事项

- 不交易；
- 不盘中临时找票；
- 不使用事件驱动失败线；
- 不追高；
- 不在同一验证样本上调参抢救；
- 不扩大 30,000 元额度；
- 不使用家庭核心资产配置资金。

## 15. 决策规则

- PASS：进入账户仿真，不直接实盘；
- EDGE：不交易，不账户仿真；
- FAIL：归档，不抢救。
